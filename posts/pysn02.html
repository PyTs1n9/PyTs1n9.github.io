Python 判断语句（二）

布尔类型

用于表示真（True）和假（False）的数据类型，是判断语句的基础

布尔类型（bool）只有两个值：True 和 False。True 表示条件成立（真），False 表示条件不成立（假）。

布尔值可以通过比较运算得到，也可以由 bool() 函数将其他数据类型转换而来：

比较运算符

用于比较两个值之间的关系，返回布尔类型的结果

比较运算符是判断语句中的核心工具，所有比较运算的结果都是布尔值（True 或 False）。

运算符 描述 示例
== 等于：比较两个值是否相等 a == b
!= 不等于：比较两个值是否不相等 a != b
> 大于：左边是否大于右边 a > b
< 小于：左边是否小于右边 a < b
>= 大于等于：左边是否大于或等于右边 a >= b
<= 小于等于：左边是否小于或等于右边 a <= b

if 语句

如果条件成立，则执行其内部包含的代码块

if 语句是判断语句中最基础的形式，当条件为 True 时，执行缩进的代码块。

  1. if 语句的基本格式
  1. if 语句的缩进规则
  1. 条件不成立时

if-else 语句

条件成立执行if代码块，不成立则执行else代码块

if-else 语句提供了两种分支路径，无论条件是否成立，总有一块代码会被执行。

  1. 基本格式
  1. 实际应用示例

if-elif-else 语句

用于处理多个条件的判断，从上到下依次判断，满足任意一个条件后不再继续

当需要判断多个互斥条件时，使用 if-elif-else 结构。elif 是 “else if” 的缩写。

  1. 基本格式
  1. elif 可以有多个，else 可以省略
  1. 将 input 与判断结合

逻辑运算符

用于连接多个条件，构建复合判断语句

当需要同时判断多个条件时，使用逻辑运算符将它们组合起来。

运算符 描述 说明
and 与 两边条件都为 True，结果才为 True
or 或 两边条件只要有一个为 True，结果就为 True
not 非 取反，True 变 False，False 变 True
  1. and 运算符（与）
  1. or 运算符（或）
  1. not 运算符（非）
  1. 多个逻辑运算符组合

嵌套判断

在一个判断语句内部再嵌套另一个判断语句，用于更复杂的条件判断

当条件需要分层判断时，可以在 if / elif / else 的代码块中继续写判断语句。

  1. 基本嵌套格式
  1. 多层嵌套示例

嵌套层次不要太多（建议不超过3层），否则代码可读性会变差。可以考虑使用逻辑运算符合并条件来减少嵌套。

三元表达式 （重点）

一种简洁的条件表达式写法，可以在一行内完成简单的条件判断和赋值

三元表达式是 if-else 的简化版本，适用于简单的条件赋值场景。

match-case 语句（Python 3.10+）

Python 3.10 引入的模式匹配语句，类似其他语言中的 switch-case

match-case 语句用于根据一个值的不同情况执行不同代码，是多分支判断的另一种写法。

  1. 基本格式
  1. match-case 与 if-elif-else 的对比

综合练习

将所学知识融会贯通，通过实际案例巩固判断语句的使用

判断语句是程序逻辑控制的核心。熟练掌握 if / elif / else、逻辑运算符，嵌套判断以及三元运算符，能让你编写出能够根据不同情况做出不同响应的程序。
